# CaptureCA

This Magisk/KernelSU module safely installs user CA certificates generated by **ProxyPin, Reqable, PCAPdroid, and Fiddler** (or similar network debugging tools) into the Android System Trust Store.

It allows you to bypass the persistent **"Network may be monitored"** warning on your device and analyze HTTPS traffic seamlessly.

## 🚀 Features
*   **Full System & APEX Integration:** Injects certificates into both `/system/etc/security/cacerts/` and Android 14–16+ Conscrypt APEX (`/apex/com.android.conscrypt/cacerts/`).
*   **Clean & Systemless:** Performs all operations systemlessly via `post-fs-data.sh` without physically modifying system partitions.
*   **SELinux & Private DNS Safe:** Properly configures `system_file` and `system_security_cacerts_file` SELinux contexts so native Android services (including **Private DNS / DoT**) work without issues under Magisk, KernelSU, and `mountify` overlays.

## 📂 Module Structure
This module follows the standard Magisk/KernelSU module hierarchy:
*   `module.prop`
*   `customize.sh`
*   `post-fs-data.sh`
*   `system/etc/security/cacerts/` (Certificate files are located here)

## 🛠️ Installation
1.  Download the latest `CaptureCA.zip` release from this repository.
2.  Open the Magisk or KernelSU application.
3.  Navigate to the **Modules** tab.
4.  Tap on **"Install from storage"** and select `CaptureCA.zip`.
5.  Reboot your device once installation is complete.
